ubuntu树莓派无屏幕远程连接

2023年06月02日 798 字 大概 3 分钟
🍓 本文内容
没有显示器，也能在 Ubuntu 电脑上远程控制树莓派：烧录系统 → 找到树莓派 IP → PuTTY 登录 → 开启 VNC 远程桌面。

🧰 1. 准备工作

硬件

硬件 说明
树莓派 这个必须有吧
SD 卡 16G 或 32G，个人推荐 32G
USB 读卡器 读 SD 卡用的，电脑自带卡槽就不需要
网线 可有可无，不过没有网线会很痛苦的

软件

① 烧录镜像工具 balenaEtcher

如果打不开，先安装 fuse，然后直接双击下载的 AppImage 文件：

树莓派安装全家桶（基本都是 Windows 软件）：Windows 版树莓派无屏幕连接

如果你用 Ubuntu，只需要拿里面的镜像文件：百度网盘，提取码：mpcq

插上 SD 卡，选择镜像，开始烧录：

② 远程登录工具 PuTTY

装好后在终端输入 putty 就能打开。

③ 找 IP 的工具 nmap

找树莓派地址是整个过程里最烦的一步，有网线还好，没网线就等着痛苦吧。

📡 2. 找到树莓派的 IP

方式 A：有网线（简单很多，推荐）

打开 Ubuntu 的网络设置：

在 IPv4 中选择 与其他计算机共享：

树莓派连上网线后，直接扫描：

💡 这种方式 IP 是不会变的 · - ·，找一次记住就行。

方式 B：无网线（连 WiFi）

需要先准备两个配置文件：

  • ssh：保持空白即可，作用是开启 SSH；
  • wpa_supplicant.conf：写入下面的内容，ssid 是 WiFi 名称，psk 是 WiFi 密码。用手机热点也行（如果手机热点能直接看到设备地址，就不用 nmap 了）。

插入 SD 卡，把这两个文件放进 boot 分区，然后扫描网段：

⚠️ 无网线方式的坑
  • 这两个文件每次启动后都会被系统“吃掉”，即使没连上 WiFi 也会消失，所以每次启动前都要重新放进 boot。
  • 树莓派的 IP 会变，每次都要重新找；找不到就重启树莓派再找一遍。

🔐 3. 用 PuTTY 登录

终端输入 putty 打开 PuTTY，在扫描结果里找到 raspberry 设备，把 IP 填进 PuTTY：

项目 默认值
用户名 pi
密码 raspberry
