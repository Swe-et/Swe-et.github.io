Ubuntu系统安装22.04版本

2023年05月28日 504 字 大概 2 分钟
🐧 本文内容
在 Windows 电脑上装 Ubuntu 22.04 双系统：分配磁盘空间 → 制作 U 盘启动盘 → 进 BIOS 从 U 盘启动 → 安装系统。

🧰 0. 安装前准备

类型 需要什么
硬件 U 盘（不要低于 16G）
软件 Rufus（制作 U 盘启动盘）
镜像 Ubuntu 22.04 桌面版镜像

💽 1. 给 Ubuntu 分配磁盘空间

打开「计算机 → 管理 → 磁盘管理」（Win11 在开始按钮上右键就能找到）。

⚠️ 需求比较大的话建议多压一点。我的 Ubuntu 给了 300G，之后扩容很麻烦！！

然后新建简单卷：

🔥 2. 制作 U 盘启动盘

把 U 盘插在电脑上，打开刚刚下载的 Rufus：

🔑 3. 从 U 盘启动

通过 BIOS 进入 U 盘里的系统：

  1. 先查清楚自己电脑进 BIOS 的按键。 不同品牌不一样，同一品牌的笔记本和台式机也可能不一样，比如联想台式机按 F1，笔记本按 Fn + F2。实在找不到就瞎按，从 F1 按到 F12。
  2. 关机，再开机，在开机画面出现时连续按进 BIOS 的快捷键。
  3. 进入 BIOS 后：关闭“安全启动”，并把 U 盘设为第一启动项（启动项里可能显示为 ubuntu 或 USB，把它置顶），保存并退出。

选择 UEFI: xxx，这个就是 U 盘：

选择第二个（第一个也行）：

然后等待开机。

🖥️ 4. 安装 Ubuntu

语言选中文也行，不改也行：

选「正常安装」也行：

⚠️ 千万别选错分区！
选错的话，那个盘里的所有东西都会没掉。

接下来设置用户名（用英文，好像也用不了中文）。密码设简单点，不然你会后悔的 🙃

等待安装完毕，重启电脑，就能进入 Ubuntu 系统了 🎉
