📖 3. 几个基础概念




概念
含义





IoU
预测框与真实框的重叠程度（交集 / 并集）




mAP
各类别平均精度（AP）的平均值，综合衡量精度和召回率




NMS（非极大值抑制）
按置信度排序，保留最高的框，去掉与它 IoU 超过阈值的重复框




BN（Batch Normalization）
在神经网络每一层对输入做归一化的方法





🏗️ 4. YOLOv5 网络结构
装好 Netron，把模型的 .pt 转成 .onnx 后，就可以可视化查看 YOLOv5 的网络结构。


（1）输入端
    

  • Mosaic 数据增强：用随机缩放、随机裁剪、随机排布的方式把多张图拼接在一起。
    • 

  • 自适应锚框计算：针对不同数据集，会有初始设定长宽的锚框。网络在初始锚框的基础上输出预测框，和真实框比对、计算差距，再反向更新，迭代网络参数。
    •

（4）Prediction
损失函数用的是 GIoU_Loss，几种 IoU Loss 的区别：






损失
考虑的因素





IoU_Loss
检测框和目标框的重叠面积




GIoU_Loss
在 IoU 基础上，解决边界框不重合时的问题




DIoU_Loss
在 IoU、GIoU 基础上，加入中心点距离




CIoU_Loss
在 DIoU 基础上，再加入宽高比的尺度信息





⚡ 5. YOLOv8
模型推理过程
    

  1. bbox 积分形式转 4d bbox：对 Head 输出的 bbox 分支，利用 Softmax 和 Conv 把积分形式转换为 4 维 bbox 格式。
    2. 

  2. 维度变换：YOLOv8 输出 80×80、40×40、20×20 三个尺度的特征图，Head 部分共输出分类和回归 6 个尺度的特征图。把 3 个尺度的类别分支、bbox 分支分别拼接并做维度变换，通道维度放到最后，shape 分别为 (b, 8400, 80) 和 (b, 8400, 4)（8400 = 80×80 + 40×40 + 20×20）。
    3. 

  3. 解码还原到原图尺度：分类分支做 Sigmoid，bbox 分支解码为原图尺度的 xyxy 格式。
    4. 

  4. 阈值过滤：遍历 batch 中每张图，用 score_thr 过滤，同时考虑 **multi_label 和 nms_pre，确保过滤后的框数不多于 nms_pre**。
    5. 

  5. 还原尺度并 NMS：根据前处理把框还原到原图尺度再做 NMS，最终输出的框数不多于 **max_per_img**。
    6.
